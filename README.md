# Expense Approval Process Redesign & Spend Analytics

End-to-end redesign of a manual expense approval process. This project combines Business Analysis (requirements, process mapping), Data Analysis (SQL, Power BI), and Financial Analysis (budget variance, cost-benefit).

## 🎯 Business Problem
A mid-size IT services firm faces a 7.2-day average approval turnaround time (TAT), financial leakage from duplicate claims, and poor compliance visibility due to a manual process.
