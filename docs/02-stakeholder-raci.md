# Stakeholder Register & RACI Matrix

## 1. Stakeholder Register
This matrix maps the influence and interest of everyone involved in the expense approval process.

| Stakeholder | Role in Process | Interest Level | Influence Level | What They Need |
|---|---|---|---|---|
| **Employee** | Submits claims | High | Low | Fast reimbursement, easy submission. |
| **Manager** | First-level approval | Medium | High | Clear policy rules, less manual work. |
| **Dept Head** | High-value approval | Medium | High | Budget control, cost optimization. |
| **Finance Team** | Compliance & audit | High | Medium | Accurate data, zero policy violations. |
| **Finance Director** | Very high-value approval | Low | High | Overall cost control, audit readiness. |
| **Auditor** | Compliance check | High | Low | Clean records, full traceability. |
| **Leadership** | Strategic oversight | High | High | Spend visibility, return on investment (ROI). |

## 2. RACI Matrix
RACI stands for: **R**esponsible (Does the work), **A**ccountable (Final owner), **C**onsulted (Gives input), **I**nformed (Kept updated).

| Key Decision / Task | Employee | Manager | Dept Head | Finance Team | Finance Director | Leadership |
|---|---|---|---|---|---|---|
| Submit expense claim | **R** | I | - | - | - | - |
| Verify receipt attached | **R** | **A** | - | C | - | - |
| Approve claims under ₹5k | - | - | - | **R/A** | - | - |
| Approve claims ₹5k - ₹25k | - | **R/A** | I | I | - | - |
| Approve claims above ₹25k | - | R | **A** | C | I | - |
| Detect duplicate claims | - | - | - | **R/A** | - | - |
| Flag policy violations | - | - | - | **R/A** | I | - |
| Monitor monthly budget | - | - | C | R | **A** | I |

## 3. Engagement Strategy
- **Finance Team & Managers:** Primary focus. The new process must make their jobs easier, not harder.
- **Employees:** Need a simple, fast interface to submit claims.
- **Leadership:** Need a dashboard that highlights overspending and bottlenecks instantly.
